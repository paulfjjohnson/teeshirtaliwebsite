# The Command Center

The Command Center is your owner control panel for the whole TSA site — sales at a glance, the production pipeline, and one-click access to every TSA tool.

## Getting there

Two ways, both **owner-only** (you must be logged in with manager access):

- The small **gear icon** in the bottom-left corner of any page. It only appears when *you* are logged in — visitors and staff without access never see it.
- Directly at **`/dashboard/`**.

If you're not logged in (or don't have manager access) the page politely refuses — this is real security, not a hidden URL.

## What's on it

- **KPIs** — sales for Today / 7 days / 30 days / All, with trend arrows.
- **Production pipeline** — how many orders sit in each stage (artwork review, processing, etc.). Anything needing action is flagged.
- **The launcher** — every TSA tool as a card, grouped into:
  - **Orders & Ops** — Orders, Requests, Reports
  - **Stores** — Stores, Store Builder, Store Settings
  - **Drops & Marketing** — Tee Parties, Alerts, Ambassadors, QR Codes, Fundraisers
  - **Catalog** — Designs, Blank Apparel
  - **Settings** — Platform, Branding, Form Emails, Help

Each card opens the matching admin screen in a new context — so the Command Center is your map, and the admin screens are where the work happens.

## Who can see it

Access is gated by the WordPress **Manage WooCommerce** capability. Give a staff member that capability (via their user role) and they get the Command Center; remove it and they don't. Every visit is tied to their own login, so you always know who did what.
