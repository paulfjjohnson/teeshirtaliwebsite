# Requests & Quote Uploads

Every submission from your **Contact, Quote, Store, Tee Party, and Fundraiser** forms lands in one inbox so nothing gets lost in email.

## The Requests inbox

Command Center → **Requests** (or wp-admin → Requests). Each row is one submission, with:

- **Type** — Quote, Contact, Store, Tee Party, Fundraiser, etc.
- **Contact** — email (click to reply) and phone.
- **File** — a 📎 **View** link when the submission included an upload.
- **Status** — **New**, **Read**, or **Done**.

New requests are counted on the dashboard, and open marks them **Read** automatically. Set a request to **Done** once you've handled it.

## Opening a request

Click a request to see the full **Request Details** — the contact info, the complete message, where it was submitted from, and, if there's an upload, an **Attachment** row with a **download link and image preview**.

## Where quote uploads are stored

Artwork uploaded through the **Request a Quote** form is saved to a tidy, dedicated folder:

`wp-content/uploads/quote-requests/YYYY/MM/`

The file's link is attached to the request record (so it's one click from the Requests inbox) and is also included in the quote email. Allowed types include PNG, JPG, PDF, SVG, EPS, and AI, up to 10 MB.

> Tip: these files are **not** added to the Media Library — they live in the folder above and are reached through the Requests inbox, keeping your Media Library clean.

## Where notifications go

Which email address each form notifies is set under **Settings → TSA Form Emails**. That's separate from where the *files* are stored — the form emails are the heads-up; the Requests inbox is the permanent record.
